# Sessão 2026-05-05 - Correções e Melhorias

## Problema 1: Rota /admin levava para página Demo

**Sintoma:** Ao acessar `/admin` o usuário era redirecionado para a página Demo.

**Causa:** Rota `/admin` estava duplicada em `App.tsx`, causando conflito no roteamento.

**Solução:** Removida a дублирующая rota em `artifacts/alan-ribeiro-catalog/src/App.tsx`:
```tsx
// ANTES (duplicado):
<Route path="/admin" component={Admin} />
<Route path="/demo" component={Demo} />
<Route path="/admin" component={Admin} />
<Route path="/vip" component={Vip} />

// DEPOIS:
<Route path="/demo" component={Demo} />
<Route path="/admin" component={Admin} />
<Route path="/vip" component={Vip} />
```

## Problema 4: Personalização do player afeta outros artistas

**Sintoma:** Cores do player de um artista afetavam outros artistas.

**Causa:** `AudioPlayer` recebia props diretamente, sem contexto compartilhado.

**Solução:** 
1. `PlayerContext` agora gerencia `playerGradient` e `playerCor` globalmente
2. `AudioPlayer` não recebe mais props, lê cores do contexto
3. `ArtistProfile` chama `setPlayerColors()` ao carregar artista
4. Reset das cores no cleanup do useEffect (ao desmontar)

```tsx
// ArtistProfile.tsx
useEffect(() => {
  if (artistData) {
    setPlayerColors(artistData.playerGradient || null, artistData.playerCor || null);
  }
  return () => setPlayerColors(null, null);
}, [artistData, setPlayerColors]);
```

## Problema 5: Prévia não mostrava banner nem capa do artista

**Sintoma:** Na prévia do perfil ("Prévia da sua página") não aparecia o banner nem a foto real.

**Causa:** 
1. URL do banner era relativa e não resolvia no CSS
2. Necessário usar aspas ao redor da URL no CSS

**Solução:**
```tsx
// ANTES:
background: artist?.bannerUrl ? `url(${artist.bannerUrl})` : ...

// DEPOIS:
backgroundImage: artist?.bannerUrl ? `url("${window.location.origin}${artist.bannerUrl}")` : ...
```

**Nota:** URLs em CSS `url()` precisam de aspas duplas para funcionar corretamente com caminhos relativos.

## Problema 6: API MercadoPago não tinha tabela subscriptions

**Verificado:** Tabela `subscriptions` não existia no banco.

**Criada:**
```sql
CREATE TABLE subscriptions (
  id SERIAL PRIMARY KEY,
  artist_id INTEGER REFERENCES artists(id) ON DELETE CASCADE,
  plan_nome TEXT NOT NULL,
  mp_payment_id TEXT,
  mp_preference_id TEXT,
  status TEXT DEFAULT 'active',
  amount TEXT,
  started_at TIMESTAMPTZ DEFAULT NOW(),
  expires_at TIMESTAMPTZ,
  created_at TIMESTAMPTZ DEFAULT NOW()
);
```

**Endpoints verificados:**
- `GET /api/payments/plans` ✅
- `POST /api/payments/create-preference` ✅
- `POST /api/webhooks/mercadopago` ✅
