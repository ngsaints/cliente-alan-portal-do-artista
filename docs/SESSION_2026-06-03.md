## 🎵 CRM — Gestão de Carreira (página dedicada)

### Estrutura
- **Rota**: `/artista/crm` — página própria com Navbar e botão `← Voltar`
- **Dashboard**: card amarelo "CRM — Gestão de Carreira" abaixo das abas (link para `/artista/crm`)
- **Sub-tabs internas**: Contatos | Financeiro | Liberações | Calendário | Ajuda

### 👥 Contatos
- CRUD completo com 6 categorias: Artista, Produtor, Editor, Empresário, Gravadora, Outro
- Campos: Nome, Categoria, Telefone, Email, Anotações
- Grid responsivo com hover para editar/excluir
- Formulário compacto com validação

### 💰 Financeiro (Plano de Contas)
- **Visão colunas**: cada categoria é uma coluna vertical com código + itens
- **Tabs DESPESAS / RECEITAS** alternam entre categorias de custo e receita
- **Coluna TOTAL**: Despesas (total), Receitas (total), Total líquido
- **Adição inline**: botão "Adicionar" em cada coluna abre campo direto
- **Resumo mensal**: tabela colapsável com Receitas, Custos, Saldo por mês
- Cálculos com `Math.abs()` — valores sempre positivos no banco, sinal aplicado no frontend
- API protegida: `POST /api/custos` e `POST /api/receitas` forçam `Math.abs()` no valor

### 🛡️ Liberações
- CRUD: música, artista, data início, data liberação
- Alerta vermelho para liberações sem data definida
- Contador de dias aguardando (`N dias aguardando`)
- Campo inline `input[type=date]` para definir data de liberação
- Histórico de concluídas colapsável (details/summary)

### 📅 Calendário
- Grid mensal com navegação ◀ ▶
- Datas clicáveis para adicionar eventos
- Eventos: título, observação, horário inicial/final
- Modal bottom-sheet no mobile / centralizado no desktop
- Edição e exclusão com hover

### 🆘 Ajuda
- Layout 2 colunas: FAQ (esquerda) + Fale Conosco (direita)
- 6 perguntas frequentes com accordion
- 3 tipos de suporte com descrição explicativa
- Mensagem enviada para API, armazenada na tabela `ajuda`

## 🔧 Correções

### React Error #310 (Rendered more hooks)
- **Causa**: `useEffect` depois de `if (loadingArtist) return` no `ArtistProfile.tsx`
- **Correção**: `useEffect` movido para ANTES do return condicional
- **CrmTabs refatorado**: `useState` plano por campo, `useCallback` para funções, sem arrays inline no JSX

### Galeria de fotos (500 no upload)
- **Causa**: `deploy.sh` deletava `/var/www/portal-do-artista` apagando uploads
- **Correção**: backup/restaura da pasta `uploads/` durante deploy
